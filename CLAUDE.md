# ТЛК БАРС — репозиторий сайта и внутренней системы

Два независимых проекта в одном репо:

- **Публичный сайт** `tlkbars.ru` — 11ty + Tailwind + TS, Decap CMS, `server/` (заявки → Bitrix24 + Telegram).
  Карта: `PROJECT-MAP.md`. Без явной просьбы сайт не менять.
- **Внутренняя система «Ирбис» `/crm/`** (база знаний, справочник для звонков, CRM: воронка, сделки-отгрузки,
  календарь, документы, контрагенты, товары) — отдельный пакет `crm/`.
  **Сначала прочитай `crm/CONTEXT.md`** — там бизнес, решения владельца и почему, архитектура, карта файлов,
  подводные камни, деплой. Справочник (схема БД, API, команды) — `crm/README.md`. Не перечитывай весь код —
  иди точечно по карте файлов.

Правила:
- Интерфейс, тексты, коммиты — на русском. Владелец пишет коротко; крупные изменения — сначала коротко
  согласовать, потом делать. Воронку продаж без просьбы не перестраивать.
- Не коммитить реальные данные клиентов/поставщиков и их документы (только вымышленные демо).
- Перед пушем: `cd crm && npm run typecheck && CRM_TEST_DATABASE_URL=postgres://crm:crm@127.0.0.1/crm_test npm test && npm run build`
  (если Postgres не запущен — `service postgresql start`).
- Схема БД меняется через `crm/server/db/schema.ts` → `npx drizzle-kit generate` → перенос данных дописывать в SQL до DROP.
- Меняешь поведение CRM — обнови `crm/CONTEXT.md` (и `crm/README.md`, если затронуты таблицы/API/команды) в том же коммите.
