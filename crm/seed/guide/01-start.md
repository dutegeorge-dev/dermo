# 1. Вход, меню, поиск и ИИ-помощник

## Вход

Адрес — **tlkbars.ru/crm**. Логин и пароль выдаёт администратор (раздел «Пользователи»). Пароль можно сменить в профиле — пункт с вашим именем внизу меню.

![Страница входа](01-login.png)

## Меню

Слева — разделы. Сверху — поиск по всему Ирбису и две кнопки, которые доступны с любой страницы: **«Спросить ИИ»** и **«Загрузить документ»**.

![Главный экран: меню слева, поиск и кнопки сверху](02-shipments-board.png)

- **База знаний** — статьи и инструкции (вы сейчас здесь).
- **Справочник для звонков** — что спросить и что ответить клиенту.
- **Сделки** — все заказы: доска по этапам, список, календарь.
- **Воронка продаж** — лиды до депозита.
- **Расчёт** — расчёты стоимости для клиентов и КП.
- **Клиенты, Фабрики, Поставщики, Подрядчики** — карточки контрагентов.
- **Документы** — все документы компании.
- **Товары** — справочник товаров с кодами ТН ВЭД, ценами фабрик и сертификатами.

Внизу меню — тёмная / светлая тема и выход.

## Поиск

Строка сверху ищет сразу по сделкам, контейнерам, клиентам, документам, товарам и базе знаний. Можно ввести номер контейнера, номер инвойса, ИНН или часть названия. Быстро открыть поиск — клавиша «/».

![Поиск: «трава» — сделки, контейнеры, лиды](26-search.png)

## ИИ-помощник

Кнопка **«Спросить ИИ»** открывает чат. Спрашивайте обычными словами по данным Ирбиса: «какие оплаты просрочены?», «где контейнер DEMU1000011?», «что по сделкам ГринЛэнда?». ИИ только читает данные и ничего не меняет. На открытой странице он понимает, о какой сделке или документе речь.

![ИИ-помощник отвечает по данным Ирбиса](27-ai-chat.png)
