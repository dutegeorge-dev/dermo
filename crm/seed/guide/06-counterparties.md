# 6. Клиенты, поставщики, подрядчики

Три справочника: **Клиенты** (кому возим), **Поставщики** (у кого покупаем), **Подрядчики** (перевозчики, брокеры, СВХ, агенты). Обычно они заводятся сами — из загруженных документов. Новые вручную — кнопкой «+ Клиент» / «+ Поставщик» / «+ Подрядчик».

![Клиенты: список](13-clients.png)

## Новый контрагент: реквизиты из текста

В форме нового клиента есть поле **«Вставить реквизиты»**: вставьте реквизиты как прислали (карточку предприятия из письма, текст из мессенджера) или приложите файл — ИИ разложит их по полям: название, ИНН, КПП, ОГРН, адрес, банк, подписант. Проверьте и сохраните.

## Карточка клиента

Вкладки: документы, сделки, товары и цены (что и почём он у нас покупал), связи, реквизиты и контакты. Сверху — кнопки:

- **«Договор комиссии»** — сформировать договор комиссии из шаблона компании: номер по порядку, реквизиты клиента подставятся сами (чего не хватает — Ирбис скажет), скачается DOCX.
- **«+ Документ»** — загрузить документ сразу для этого клиента.

![Карточка клиента](14-client-card.png)

> Загрузили подписанный договор комиссии файлом — Ирбис сам создаст клиента с реквизитами из договора, если такого ещё нет.

## Поставщики и подрядчики

Устроены так же. У поставщика видно его товары и цены, декларации соответствия на его товары. У подрядчика — вид (перевозчик в Китае / в России, брокер, СВХ, агент): от него зависит, к какой статье расходов относятся его счета.

## E-mail для рассылки

На странице «Клиенты» кнопка «E-mail для рассылки» собирает адреса клиентов одним списком — удобно вставить в почту.
